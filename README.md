# PyCalc

## Advanced Math Toolkit

PyCalc is a Python-based mathematical toolkit designed to perform different types of calculations through a simple and organized command-line interface.

## Version

**v1.3.0**

## Features

### 1. Basic Calculator

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Modulus

### 2. Quadratic Equations

* One Quadratic Equation
* System of Two Equations
* System of Three Equations
* Discriminant & Root Analysis

### 3. Geometry

* Circle

  * Area
  * Circumference
  * Diameter
* Rectangle

  * Area
  * Perimeter
  * Diagonal
* Square

  * Area
  * Perimeter
  * Diagonal
* Triangle

  * Area
  * Perimeter
* Cube

  * Volume
  * Total Surface Area
  * Diagonal
* Sphere

  * Volume
  * Surface Area
  * Diameter
* Cylinder

  * Volume
  * Total Surface Area
  * Lateral Surface Area

### 4. Calculation History

* View calculation history
* Clear calculation history
* Save calculations using the History module
